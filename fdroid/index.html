Wi-Fi Notifier

An Android app that does one thing: it tells you the name of the Wi-Fi network your phone has joined. There is no screen — the app lives in the notification shade.

Add to F-Droid

In the F-Droid client: Settings → Repositories → Add repository, then paste:

https://1buran.github.io/wifi-notifier/repo

F-Droid shows this fingerprint on the first use; it signs the repository index:

3D:BC:FB:C0:E4:BC:36:01:E4:50:8A:96:01:E6:51:10
38:7E:F3:1E:D6:87:BA:1D:E5:A5:16:2D:46:82:28:0C

Direct download

app-release.apk — the same build, signed with the release key. Android refuses to update an app whose signature changed, so this APK and the F-Droid one are interchangeable, the official F-Droid build is not.
